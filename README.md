# 🚀 Interactive 3D Portfolio Website

An immersive and modern **portfolio website** built to showcase my projects, skills, and development work through **interactive UI, smooth animations, and 3D visuals**.

This project goes beyond a traditional portfolio by combining **creative design, performance, and interactivity** to deliver a memorable user experience for users and recruiters.

![Portfolio Preview](public/images/preview.png)

---

## ✨ Features

- 🎯 Smooth animations using GSAP  
- 🌐 Interactive 3D elements with Three.js & WebGL  
- ⚡ Optimized performance and fast loading  
- 📱 Fully responsive design  
- 🧩 Clean and scalable code structure  
- 🎨 Modern UI with engaging transitions  

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript  
- **Animation:** GSAP  
- **3D & Graphics:** Three.js, WebGL  
- **Styling:** HTML, CSS, JavaScript
